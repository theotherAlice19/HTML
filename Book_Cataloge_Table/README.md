## Book Catalog
A simple book catalog page built with HTML. Displays a structured table of classic books with their title, author, genre, and publication year, along with a footer showing the total number of books.

## What Is This Project?
This project is a minimal book catalog page. It features a single HTML table with a header, five book entries, and a footer row, practicing the use of HTML table elements and their structure.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Table structure (`<table>`, `<thead>`, `<tbody>`, `<tfoot>`)
- Table rows and cells (`<tr>`, `<th>`, `<td>`)
- Spanning columns (`colspan`)
- Organizing and displaying tabular data

## What I Built With?
- HTML5
