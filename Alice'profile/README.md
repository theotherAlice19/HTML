## Alice's Profile Page
A simple personal profile page built with HTML. Displays a brief introduction and goals for a full-stack web development student named Alice.

## What Is This Project?
This project is a minimal personal profile page for Alice. It features a welcome heading, an introduction section, and a goals section, practicing basic HTML document structure and text elements.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Metadata elements (`<meta charset>`, `<meta name="viewport">`)
- Headings (`<h1>`, `<h2>`)
- Paragraph elements (`<p>`)

## What I Built With?
- HTML5
