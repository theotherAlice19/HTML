## HTML First Project
A simple web page built with HTML. Displays an overview of the freeCodeCamp full-stack curriculum, introducing HTML, CSS, and JavaScript with short descriptions for each.

## What Is This Project?
This project is a minimal curriculum overview page for freeCodeCamp. It features a welcome heading, a curriculum title, and three topic sections each with a short description, practicing basic HTML document structure and text hierarchy.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Metadata elements (`<meta charset>`, `<meta name="viewport">`)
- Headings hierarchy (`<h1>`, `<h2>`, `<h3>`)
- Paragraph elements (`<p>`)

## What I Built With?
- HTML5
