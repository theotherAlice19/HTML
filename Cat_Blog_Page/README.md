## Mr. Whiskers' Blog Page
A simple blog page built with HTML. Displays a personal blog about a cat named Mr. Whiskers, featuring a profile image, navigation links, an about section, blog posts, and a contact section.

## What Is This Project?
This project simulates a minimal personal blog page for a cat owner named Jane Doe. It features a header with an image and navigation, three blog post articles, and a footer with contact details, practicing semantic HTML structure and page organization.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Semantic layout elements (`<header>`, `<main>`, `<footer>`, `<section>`, `<article>`)
- Navigation with anchor links (`<nav>`, `<a href="#">`)
- Images and captions (`<img>`, `<figure>`, `<figcaption>`)
- Contact information (`<address>`, `<a href="tel:">`, `<a href="mailto:">`)
- Headings and paragraph elements

## What I Built With?
- HTML5
