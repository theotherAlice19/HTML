## Hotel Feedback Form
A simple hotel feedback form built with HTML. Collects guest information, stay history, reasons for choosing the hotel, service ratings, and additional comments through a structured and accessible form.

## What Is This Project?
This project is a minimal hotel feedback form page. It features four fieldsets covering personal information, radio button selection, checkboxes, and dropdown ratings, practicing a wide range of HTML form elements and their attributes.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Semantic layout elements (`<header>`, `<main>`)
- Form structure (`<form>`, `<fieldset>`, `<legend>`)
- Text, email, and number inputs (`<input type="text/email/number">`)
- Input attributes (`placeholder`, `required`, `min`, `max`, `size`)
- Radio buttons (`<input type="radio">`)
- Checkboxes (`<input type="checkbox">`, `checked`)
- Dropdown menus (`<select>`, `<option>`, `selected`)
- Textarea for long responses (`<textarea>`)
- Submit button (`<button type="submit">`)
- Accessible labels (`<label for="">`)

## What I Built With?
- HTML5
