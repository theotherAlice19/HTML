## Heart Icon
A simple web page built with HTML and SVG. Displays a red heart icon using an inline SVG element with a custom path.

## What Is This Project?
This project is a minimal icon page featuring a red heart shape. It uses an inline SVG element with a `path` to draw the heart, practicing the basics of embedding scalable vector graphics directly into HTML.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Inline SVG elements (`<svg>`)
- SVG attributes (`viewBox`, `width`, `height`, `fill`)
- SVG path drawing (`<path>`, `d` attribute)

## What I Built With?
- HTML5
- SVG
