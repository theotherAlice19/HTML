## Calculus Final Exams Table
A simple grade table page built with HTML. Displays a structured table of calculus final exam results with student names and grades, along with a footer showing the class average.

## What Is This Project?
This project is a minimal exam results page. It features a single HTML table with a caption, five student entries, and a footer row displaying the average grade, practicing the use of HTML table elements and their structure.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Table structure (`<table>`, `<thead>`, `<tbody>`, `<tfoot>`)
- Table caption (`<caption>`)
- Table rows and cells (`<tr>`, `<th>`, `<td>`)
- Spanning columns (`colspan`)
- Organizing and displaying tabular data

## What I Built With?
- HTML5
