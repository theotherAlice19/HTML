## XYZ Bookstore Page
A simple bookstore product page built with HTML. Displays a collection of books as cards, each with a title, description, and a "Buy Now" button — along with cart and checkout actions at the bottom.

## What Is This Project?
This project simulates a minimal e-commerce book listing page for **XYZ Bookstore**. It features two book cards and a checkout section, practicing HTML structure, `div` containers, IDs, classes, and button elements.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- `<div>` containers for grouping and layout
- CSS class and ID attributes (`class`, `id`)
- Headings and paragraph elements
- `<button>` elements and their attributes
- Organizing content into reusable card components

## What I Built With?
- HTML5
