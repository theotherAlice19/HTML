## Display Videos in an iframe
A simple web page built with HTML. Displays an embedded YouTube video using an iframe element with full playback permissions and fullscreen support.

## What Is This Project?
This project is a minimal video display page focused on the HTML `<iframe>` element. It features a single embedded YouTube video, practicing how to embed third-party content into a webpage using iframes and their security and permission attributes.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Embedding external content (`<iframe>`)
- iframe attributes (`width`, `height`, `src`, `allowfullscreen`)
- Permission policies (`allow`, `referrerpolicy`)
- Embedding YouTube videos using the embed URL format

## What I Built With?
- HTML5
