## Travel Agency Page
A simple travel agency web page built with HTML. Displays a collection of travel destinations and packages, featuring linked images, captions, and a list of tour options.

## What Is This Project?
This project is a minimal travel agency landing page. It features a welcome section, a list of travel packages, and three destination figures with linked images and captions, practicing semantic HTML structure, links, images, and lists.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Metadata elements (`<meta charset>`, `<meta name="description">`)
- Headings and paragraph elements (`<h1>`, `<h2>`, `<p>`)
- Unordered lists (`<ul>`, `<li>`)
- Anchor links with `target="_blank"` (`<a>`)
- Images and captions (`<img>`, `<figure>`, `<figcaption>`)
- Wrapping images inside anchor tags

## What I Built With?
- HTML5
