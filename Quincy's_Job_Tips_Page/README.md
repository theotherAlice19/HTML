## Quincy's Tips for Getting a Developer Job
A simple web page built with HTML. Displays a collection of tips and quotes from Quincy Larson about landing your first developer job, covering mindset, networking, and building a reputation.

## What Is This Project?
This project is a minimal inspirational reference page based on Quincy Larson's book. It features three sections of quoted advice presented using semantic HTML quotation elements, practicing proper document structure and content organization.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Semantic sectioning elements (`<main>`, `<section>`)
- Inline and block quotations (`<q>`, `<blockquote>`, `<cite>`)
- Headings and paragraph elements
- HTML entities (`&mdash;`)
- Citing external sources with the `cite` attribute

## What I Built With?
- HTML5
