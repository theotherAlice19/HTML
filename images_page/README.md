## Images Page
A simple web page built with HTML. Displays a collection of three placeholder images with titles, alt text, and defined dimensions.

## What Is This Project?
This project is a minimal image display page. It features three images loaded from an external placeholder service, practicing the use of the HTML `<img>` element and its attributes for accessibility and layout control.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Image elements (`<img>`)
- Image attributes (`src`, `alt`, `width`, `height`, `title`)
- Linking external image sources
- Writing descriptive alt text for accessibility

## What I Built With?
- HTML5
