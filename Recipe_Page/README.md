## Recipe Page — Chocolate Chip Cookies

A simple recipe page built with HTML. Displays a classic chocolate chip cookie recipe with an image, ingredients list, and step-by-step instructions.

## What Is This Project?

This page presents a full recipe for soft and chewy chocolate chip cookies, structured using semantic HTML. It practices content organization with headings, lists, and images — the core building blocks of any recipe or article page.

## What I Practiced?

- HTML document structure (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`)
- Headings hierarchy (`<h1>`, `<h2>`)
- Paragraphs for descriptive content
- Images with `src` and `alt` attributes
- Unordered list (`<ul>`) for ingredients
- Ordered list (`<ol>`) for step-by-step instructions
- `charset` and `<title>` metadata

## With What I Built With?

- HTML5
