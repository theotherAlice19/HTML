## Useful Links Page
A simple web page built with HTML. Displays a list of useful links that open in a new tab when clicked.

## What Is This Project?
This project is a minimal link collection page. It features three external links organized in an unordered list, practicing the use of anchor elements and their attributes.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Metadata elements (`<meta charset>`, `<meta name="viewport">`)
- Unordered lists (`<ul>`, `<li>`)
- Anchor links (`<a href="">`, `target="_blank"`)
- Opening links in a new tab

## What I Built With?
- HTML5
