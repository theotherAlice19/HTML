## Working with the HTML Video Element
A simple video player page built with HTML. Displays a single video with multiple format sources, a poster image, and playback controls.

## What Is This Project?
This project is a minimal video player page focused on the HTML `<video>` element. It features a video with four source format fallbacks and a custom poster image, practicing video embedding, browser compatibility, and media attributes.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Video embedding (`<video>`, `<source>`)
- Video attributes (`controls`, `loop`, `muted`, `poster`, `width`)
- Multiple source formats for browser compatibility (`mp4`, `webm`, `ogg`, `mov`)
- Linking external media sources and poster images

## What I Built With?
- HTML5
