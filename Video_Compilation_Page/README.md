## Video Compilation Page
A simple video compilation page built with HTML. Displays a collection of favorite educational YouTube videos covering JavaScript, HTML & CSS, and responsive web design.

## What Is This Project?
This project is a minimal learning resource page. It features three sections each containing an embedded YouTube video with a title and description, practicing semantic HTML structure and iframe embedding.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Semantic layout elements (`<main>`, `<section>`)
- Headings and paragraph elements (`<h1>`, `<h2>`, `<p>`)
- Embedding external content (`<iframe>`)
- iframe attributes (`width`, `height`, `src`, `title`, `allowfullscreen`)
- Embedding YouTube videos using the embed URL format

## What I Built With?
- HTML5
