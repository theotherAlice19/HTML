## Event Hub
A simple event listing page built with HTML. Displays upcoming and past tech events with descriptions and images, along with a navigation bar for quick access to each section.

## What Is This Project?
This project is a minimal event hub page. It features a header with navigation links, an upcoming events section with two articles, and a past events section with two articles and images, practicing semantic HTML structure and internal page navigation.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Semantic layout elements (`<header>`, `<main>`, `<section>`, `<article>`)
- Navigation with anchor links (`<nav>`, `<a href="#">`)
- Headings and paragraph elements (`<h1>`, `<h2>`, `<h3>`, `<p>`)
- Images with alt text (`<img>`)
- Linking to page sections using IDs

## What I Built With?
- HTML5
