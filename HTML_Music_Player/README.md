## freeCodeCamp Tunes
A simple music player page built with HTML. Displays three audio tracks by Quincy Larson with playback controls and looping enabled for each song.

## What Is This Project?
This project is a minimal audio player page focused on the HTML `<audio>` element. It features three songs each with a title, artist name, and an embedded audio player, practicing the use of the audio element and its attributes.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Audio embedding (`<audio>`)
- Audio attributes (`src`, `controls`, `loop`)
- Headings and paragraph elements (`<h1>`, `<h2>`, `<p>`)
- Linking external audio sources

## What I Built With?
- HTML5
