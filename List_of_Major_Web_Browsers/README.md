## List of Browsers and Descriptions
A simple web page built with HTML. Displays a list of major web browsers using a description list, each with a name and a short description of its origin and developer.

## What Is This Project?
This project is a minimal browser reference page. It features five major web browsers presented using a semantic HTML description list (`<dl>`), practicing proper document structure and the use of definition terms and descriptions.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Semantic description lists (`<dl>`, `<dt>`, `<dd>`)
- Headings and metadata elements
- Organizing related content into term/description pairs

## What I Built With?
- HTML5
