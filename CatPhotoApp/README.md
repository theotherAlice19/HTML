## CatPhotoApp
A simple cat-themed web page built with HTML. Displays cat photos, a list of things cats love and hate, and a footer with a copyright notice.

## What Is This Project?
This project is a minimal cat photo application page. It features two sections — one for cat photos with external links, and one for cat lists with images and captions — practicing semantic HTML structure, links, lists, and media elements.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Semantic layout elements (`<main>`, `<section>`, `<footer>`)
- Links and anchor elements (`<a href="">`, `target="_blank"`)
- Images and captions (`<img>`, `<figure>`, `<figcaption>`)
- Ordered and unordered lists (`<ol>`, `<ul>`, `<li>`)
- Text emphasis elements (`<em>`, `<strong>`)
- Wrapping images inside anchor tags

## What I Built With?
- HTML5
