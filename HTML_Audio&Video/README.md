## HTML Audio and Video Lab
A simple media page built with HTML. Displays an embedded video player and an audio player, each loaded from an external source.

## What Is This Project?
This project is a minimal audio and video player page. It features two sections — one for video playback and one for audio playback — practicing the use of HTML media elements and their attributes.

## What I Practiced?
- HTML document structure (`<html>`, `<head>`, `<body>`)
- Semantic sectioning elements (`<section>`)
- Video embedding (`<video>`, `<source>`, `controls`, `width`)
- Audio embedding (`<audio>`, `controls`, `loop`, `src`)
- Linking external media sources

## What I Built With?
- HTML5
